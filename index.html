EV Fleet Event Pipeline

Independent project

A webhook-driven pipeline that turns an abnormal battery reading into a stored alert and an open work order with no manual steps.

PythonFastAPIPostgreSQLREST APIsWebhooks
Show details

Simulated bus telemetry is posted to a FastAPI endpoint, validated, and stored idempotently in Postgres, so duplicated or retried events are recorded once. A rule raises an alert, which is enriched with ambient temperature from the Open-Meteo API and opens a GitHub Issue as the work order.

4 systems connected3x retries with exponential backoff1 reading in, alert and work order out

The design centres on failure: the alert is committed before any third-party call, and anything that still fails is logged to a table instead of lost. Simulated data only.
